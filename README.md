# 爆炒空心菜的飞书 CLI · 智能体演示

这是一个脱敏的飞书桌面端交互原型，围绕“个人 PM 管家 → 晚间复盘 → Skill 工作流 → 老板驾驶舱”展开。

## 已实现的演示链路

- 三栏飞书桌面端外壳：应用导航、会话列表、机器人会话。
- 个人管家：收件箱归档、晚间复盘计划、资料来源和 PM Skill 编排。
- 老板驾驶舱：本周需求 FR 的业务线 / PM 指标、来源和指标口径。
- 安全执行：发送通知前展示收件人、草稿和确认步骤；演示确认不会真实发送消息。
- 会话输入：支持输入问题、Enter 发送和选择本地附件（仅演示，不上传）。

## 说明

页面使用脱敏模拟数据，不保存真实凭据，不读取真实飞书数据，也不会真实发送消息。后续接入真实系统时，需要单独实现事件接收、模型调用、权限范围、存储和审计。

## 本地运行

```bash
npm install
npm run dev
```

推送到 `main` 后，GitHub Actions 会构建静态页面并发布到仓库的 GitHub Pages。
